Numo is a desktop app built with **Tauri + React + TypeScript + Vite** for structured focus and learning flows.
It ships as a local desktop experience with lightweight UI and native packaging.

## Features

- Desktop-first app shell via Tauri
- React UI with typed state and settings
- Fast dev/build workflow with Vite
- Test support with Vitest
